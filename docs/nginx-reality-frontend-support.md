# 443 SNI 前置验证与支持状态

记录日期：2026-11-04

本页记录目前可复核的测试证据与边界。以下结果不是完整的产品支持承诺；完整发布验收仍未完成。

## 已完成的隔离真实运行验证

### 两个 Reality 后端与网站分支：`test-reality-443-netns.sh`

实验在一次临时网络命名空间中进行，只有回环接口，没有触碰宿主机端口或服务。环境为 Ubuntu 24.04.5 amd64、从 Ubuntu 发行包提取的 Nginx 1.24.0，以及已安装的 sing-box 1.14.3。Nginx 在命名空间内监听回环 TCP 443。

| 检查 | 结果 |
| --- | --- |
| Nginx 模块 | 实际加载 `ngx_stream_module.so`；构建参数含 `--with-stream=dynamic` 和 `--with-stream_ssl_preread_module`。 |
| Nginx 完整配置检查 | `nginx -t` 成功，退出码 0。 |
| sing-box 配置检查 | 1.14.3 的客户端和服务端配置均通过 `check`，退出码 0。 |
| Reality 客户端 | 两个真实客户端分别使用两个 SNI，均到达对应后端；整体验证脚本退出码 0。 |
| 网站分支 | 同一个 SNI map 入口中的网站分支成功到达网站后端。 |
| 错误认证 | 错误 UUID 的 `curl` 退出码 52；错误 Reality 公钥退出码 97；错误 short_id 退出码 97。三次均未获得代理转发；整体验证脚本以 0 退出。 |
| 较长传输 | `preread_timeout` 为 5s 时，8 秒、80 字节的传输完成。此结果只说明握手后的传输没有被这个预读超时截断。 |

### 未知 SNI：`test-stream-runtime.sh`

单独的 Nginx stream smoke test 在宿主机网络命名空间中使用提取的 Nginx 和独立 prefix，临时绑定回环 TCP 18443，并观察到未知 SNI 连接被关闭；它没有使用系统 Nginx 或其服务管理器。它不是 TCP 443 Reality 测试的一部分，不能据此声称公网 443 的未知或空 SNI 行为已验收。

只有 `test-reality-443-netns.sh` 在临时网络命名空间中运行，未触碰宿主机端口或服务。18443 smoke test 临时使用了本机回环高端口。两项测试都没有从公网访问。记录的 `curl` 退出码只描述本次实验结果，不定义为 one-singbox 的通用错误码。

以上结果不证明安装脚本、服务管理器、其他系统或公网网络路径可用。

## 自动化离线回归

发布工作流会在版本号变更、创建发布标签和打包之前运行以下离线回归，并对仓库中的所有 `.sh` 脚本执行 `bash -n`：

| 检查 | 覆盖边界 |
| --- | --- |
| `tests-nginx-reality-frontend.sh` | 两份 core 的状态、检测、入口接入、配置校验、失败恢复和中断恢复；外部 Nginx 与服务管理器由测试替身提供。 |
| `tests-nginx-reality-node-bindings.sh` | 两份 core 的绑定与节点变更联动、回滚和恢复；外部 Nginx 与服务管理器由测试替身提供。 |
| `tests-node-name-label.sh` | 节点名称、分享信息及元数据回归。 |
| `tests-node-proxy-outbound.sh` | 代理出站及节点生命周期回归；外部系统服务和 sing-box 由测试替身提供。 |
| `tests-skill-inventory.sh` | 非交互式节点、转发和日志盘点工具回归。 |

这些脚本验证离线行为，不替代真实服务管理器或真实安装制品验收。门禁中的测试失败会阻止版本号变更与打包；脚本退出码不会被忽略。

以下既有回归在当前基线上已知失败，与本次前置功能门禁分开处理，未加入该门禁：`tests-relay-support.sh`、`tests-node-share-qrcode.sh`、`tests-qrcode-deps.sh`、`tests-snell-support.sh`、`tests-log-limit.sh`。它们的失败不会通过忽略退出码或其他方式隐藏。
