## What to build

达成 Issue #76 的核心验收目标，实现白名单与节点出站的精确绑定，以及屏蔽开启状态下的原子出站切换：
- 白名单规则解绑直连：开启“屏蔽回国”时，海外基础设施白名单放行流量严格送往该节点自身的受管出站（若节点为 SS，则白名单走 SS；若节点为直连，则走直连），彻底杜绝直连泄露。
- 中国路由及私网拦截规则限定在受管代理节点的 `inbound` 范围内，采用 `action: "reject"`。
- 在保持“屏蔽回国”开启的状态下，直接修改节点出站方式（如由直连切换至 SS，或从 SS 切换至 VLESS）：
  - 旧受管出站对象被安全清理；
  - 旧节点默认路由与旧白名单规则被完整替换为新出站规则；
  - 保留明确的自定义特殊出站规则；
  - 核心校验通过后原子生效热重启；校验失败安全回滚。
- 多节点场景下各节点规则块完全隔离，节点 A 的出站变更或删除完全不影响节点 B。

## Acceptance criteria

- [ ] 节点默认出站为 SS 时，白名单放行流量走该节点 SS，不走 VPS 本机直连
- [ ] 节点默认出站为 SS 时，普通外网流量走该节点 SS，命中中国路由/私网流量被 reject
- [ ] 在开启屏蔽回国功能的前提下，直接把节点出站从直连改为 SS，无需关闭屏蔽功能即可平滑完成规则迁移
- [ ] 在开启屏蔽回国功能的前提下，把节点出站从 SS 改为 VLESS 或直连，旧 SS outbound 和旧规则被彻底移除或更新
- [ ] 多节点互不影响：修改节点 A 的出站，节点 B 的白名单与默认出站保持不变
- [ ] 删除节点时，其专属的出站对象、白名单规则与默认路由被整洁清理，不留孤儿配置
- [ ] 补充端到端回归测试套件，全面覆盖屏蔽功能开启前后、以及开启后切换出站模式的场景
