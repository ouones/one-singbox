## What to build

为所有受管节点建立明确的基准出站模型与安全的原子运维生命周期：
- 节点出站方式限定于既有的 6 种明确类型（IPv4 优先、IPv6 优先、仅 IPv4、仅 IPv6、SS 出口、VLESS 出口）。
- 新增节点与历史未显式配置出站的节点，在加载/升级时全自动平滑初始化为“IPv4 优先”（`V4优先`，对应 sing-box 原生 `prefer_ipv4` 策略），消除无出站的未管理状态。
- 建立节点与其运行时受管出站 tag（`direct_v4_pref`、`managed_node_ss_*`、`managed_node_vless_*` 等）的单向确定映射。
- 节点出站变更时，先在临时区构建候选配置并调用 `sing-box check` 预检；预检失败时立刻放弃应用，保持磁盘元数据与配置完好，向终端汇报失败原因。

## Acceptance criteria

- [ ] 新建节点自动包含 `outbound_mode: "V4优先"` 元数据记录
- [ ] 升级老旧节点时，未设置出站方式的节点自动平滑补充为 `V4优先`，零报错、不中断网络
- [ ] 修改节点出站（如从直连切换到 SS/VLESS）时，先执行核心 check 校验
- [ ] 模拟非法出站配置时，核心校验失败触发自动回滚，现有配置与服务运行不受损害
- [ ] 成功切换出站后，终端仅输出简洁的状态提示，不打印冗余过程日志
