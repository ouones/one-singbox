## What to build

重构路由生成引擎，实现节点自包含规则块（Per-node Rule Block）与精准的入站作用域隔离：
- 常态化启用路由嗅探：对所有受管代理节点入站（限定 `inbound` 列表）常态化注入 `action: "sniff"`，不论是否开启屏蔽回国。
- 确保特殊分流优先级：用户在配置中手写的自定义特殊规则（如 YouTube/Netflix -> 特殊出口）始终位于受管代理出站规则之前，解决未开启屏蔽回国时自定义分流被代理出站抢先截胡的缺陷。
- 为每个受管节点生成限定其 `inbound` 的默认路由规则，指向该节点的实际出站 tag。
- 端口中转（Relay，`relay-*.json`）与未受管入站不注入代理规则与嗅探，直接走系统兜底，彻底杜绝误伤。

## Acceptance criteria

- [ ] 嗅探规则包含 `inbound: [所有受管节点]` 作用域，不影响端口中转（Relay）
- [ ] 无论“屏蔽回国”功能开启与否，受管代理节点均常态化保持路由嗅探
- [ ] 用户手写的自定义特殊分流规则（如 YouTube 走专用出站）在未开启屏蔽回国时依然稳定生效，排在节点默认出站之前
- [ ] 每个节点拥有独立的 inbound-scoped 默认出站路由，不再依赖全局抽象的 `route.final`
- [ ] 端口中转流量（包括向国内 IP 发起的端口转发）在各类场景下均正常直连，不受嗅探和代理出站影响
